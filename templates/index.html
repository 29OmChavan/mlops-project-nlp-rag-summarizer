Portfolio Project 03 • Engineering Walkthrough

What This Project Is & How I Engineered It From First Principles

Enterprise incident response and SRE teams drown in noisy multi-speaker outage transcripts and scattered architecture runbooks. Standard off-the-shelf LLMs hallucinate citations, miss domain acronyms (LoRA, RRF, KS-drift), and cost too much to fine-tune across all weights. I built this production 6-stage NLP & Hybrid RAG platform to solve both problems: parameter-efficient fine-tuning (PEFT LoRA on Flan-T5) for multi-persona incident summarization, coupled with a Qdrant + BM25 Reciprocal Rank Fusion (RRF) Hybrid RAG engine with sentence-level hallucination attribution.

Step 1 • First-Principles LLM Core

BPE Tokenizer, Causal MHA & LoRA Math

Before using Hugging Face PEFT, I implemented BytePairTokenizerFromScratch (UTF-8 byte pair frequency merging), ScaledDotProductMultiHeadAttention with upper-triangular causal masking, and LoRALinearFromScratch ($h = W_0 x + \frac{\alpha}{r} B A x$) with zero-initialized $B=0$ so $\Delta W = 0$ at step 0.

Step 2 • PEFT LoRA & Quality Gate

98.8% Parameter Reduction + ROUGE Gate

I fine-tuned google/flan-t5-small adapters on technical incident dialogues, logging every run to MLflow/DagsHub and enforcing an automated CI/CD evaluation gate (ROUGE-1 ≥ 0.32, ROUGE-L ≥ 0.28) before artifact promotion.

Step 3 • Advanced Hybrid RRF RAG

Qdrant Dense + BM25 Lexical + Citations

Naive dense vectors miss exact acronyms. I built a dual-index retriever combining Qdrant cosine vectors + BM25 Okapi lexical search fused via Reciprocal Rank Fusion ($\text{RRF}(d) = \sum \frac{1}{k + r_i}$) + acronym expansion + claim-level faithfulness verification.
